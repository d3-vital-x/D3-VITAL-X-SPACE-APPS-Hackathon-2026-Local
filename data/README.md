# External Research Data

D³ VITAL-X keeps large scientific datasets outside the public GitHub repository to avoid unnecessary repository size and preserve source-data provenance.

Data access is provided through:

* **Official NASA / MAST archive references.**
* **Official PhysioNet dataset references.**
* **Google Drive links for selected processed science products and derived test datasets.**

The repository stores documentation and validation information, not copies of the large raw data files.

For the complete inventory and data links, see:

[`docs/DATA_MANIFEST_AND_PROVENANCE.md`](docs/DATA_MANIFEST_AND_PROVENANCE.md)

Important: The 8.71 MB biomedical CSV is a derived research stress-test dataset based on public PhysioNet ECG and recorded noise data. It is not astronaut medical data.
